- 编辑器：VS Code（中文包 / Live Server / Auto Rename Tag / Prettier / ESLint）

- 浏览器：Edge（Chromium 内核，无需谷歌账户）
- 版本控制：Git + GitHub，只有 main 一条分支

## 规矩（摘自唯一执行表）

- 代码自己写；新建的 .js 文件每行写中文注释。
- 原始数据先复制一份进 `data/raw/`，之后只改副本，原件不覆盖。
- 每份点位数据配一张数据卡：来源网址、坐标系、条数、字段、署名要求。
- 只把公开、可署名的数据发到公网；来路不明的测绘数据、单位内部点位、带个人信息的表格一律不上线；底图按来源要求署名。
- 每 2 周至少新增 1 个能打开的在线链接；写在本机、没上线的代码不算作品。
- 在线链接打不开时，当天只修这一件事，不往下学新内容。
