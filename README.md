# webgis-learning

我的 WebGIS 12 个月学习实践仓库。用 commit 记录每天走过的路。

## 学习路线（依据《WebGIS 12 个月学习计划与资源手册》）

| 阶段 | 内容 | 周次 | 核心产出 |
| ---- | ---- | ---- | ---- |
| 0 | 前端三件套 + 工程化基础 | 1–6 | 静态页面 + API 小应用 |
| 1 | Vue3 + 工程化 | 7–10 | 后台管理系统 |
| 2 | 二维 WebGIS（Leaflet → OpenLayers） | 11–16 | 图们市 POI 查询 / 旅游地图 |
| 3 | 三维 WebGIS（Cesium） | 17–26 | 三维城市场景 |
| 4 | 后端与空间数据（Node / PostGIS / GeoServer） | 27–32 | 全栈 GIS 应用 |
| 5 | 综合项目 + 作品集 + 求职 | 33–48+ | 2 个完整项目 + 部署 + 简历 |

## 开发环境

- 编辑器：VS Code（中文包 / Live Server / Auto Rename Tag / Prettier / ESLint）
- 运行时：Node.js LTS
- 浏览器：Edge（Chromium 内核）
- 版本控制：Git + GitHub

## 目录规范

- `week-01` ~ `week-48`：每周的练习代码
- `notes`：学习笔记
- `projects`：阶段项目
